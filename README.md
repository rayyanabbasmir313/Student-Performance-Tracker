Student Performance Tracker

A beginner Python command-line application for managing and analysing student performance.

Project Overview - 
1. The Student Performance Tracker allows users to:
2. View existing student records
3. Add new students
4. Calculate the average marks of the class
5. Find the student with the highest marks
6. Search for a student by name
7. Validate user input
8. Handle invalid input using exception handling
9. Exit the application through a menu-driven interface

Technologies Used - 
1. Python3
2. Lists/Dictionaries
3. Functions
4. Loops
5. Conditional statements
6. Exception handling
7. Input validation
8. Command-line interface (CLI)

Features

1. Display Students

Displays the current student records, including:

 - Name
 - Age
 - Subject
 - Marks

2. Add a Student

Users can add a new student by entering:

- Student name

- Age

- Subject

- Marks

The program validates the entered age, subject and marks before adding the student.

3. Calculate Class Average

The application calculates the average marks across all students.

4. Find Top Student

The application searches through the student records and identifies the student with the highest mark.

5. Search for a Student

Users can search for a student by entering their name.

6. Input Validation

The application checks for invalid input, including:

- Non-numeric ages

- Negative ages

- Empty subjects

- Invalid subject characters

- Non-numeric marks

- Marks outside the 0–100 range

  Invalid input is handled without crashing the program.
